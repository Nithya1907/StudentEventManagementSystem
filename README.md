\# Student Event Management System



\## Objective

A college website that allows students to view events and register for them.



\## Features

\- Event listing

\- Student event registration

\- Event management for administrators

\- User-friendly interface



\## Technologies

\- HTML

\- CSS

\- JavaScript

\- Git and GitHub



\## Team

Four developers work on separate feature branches.



\## Note

This is a learning prototype. It does not use a database or provide

real authentication. Event data is managed in browser memory.
